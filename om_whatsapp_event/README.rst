==========================================
WhatsApp Event Registrations and Reminders
==========================================

WhatsApp in the communication of events, through the Odoo Mates WhatsApp
connector. Installed by itself when Events and the WhatsApp connector are both
installed.

* The **Communication** tab of an event, or of an event template, takes
  WhatsApp templates next to the email ones, with the same triggers: after
  each registration, before or after the event.
* Two templates are ready: **Event: Registration** (the confirmation) and
  **Event: Reminder**, with the dates and the address of the event.
* The **account** is set in *Events > Configuration > Settings > WhatsApp*.

Each attendee with a valid mobile number gets the message on their
registration, where it is kept; opted-out numbers are skipped, and a problem
when sending never stops the registration.
