Features

A closer look

Reading

Upload the bill, check it, post it

Use the Upload button of the vendor bills, or let your suppliers email the purchase journal: each PDF or image becomes a draft bill, already filled in, with the document beside it.

✓  The vendor by its tax number, bank account, email or name, never your own company.
✓  The bill number, the bill and due dates, the currency and the purchase order number.
✓  The untaxed amount, the taxes and the total, cross-checked.
✓  The lines of the table, or one line with the right amount when they do not add up.
✓  Bills in English, French, German and Spanish.
Learning

Every bill you post teaches the next one

✓  The labels the vendor prints before its number, its dates and its total.
✓  How it writes its dates: is 04/03 the 4th of March or the 3rd of April?
✓  The account, the taxes and the product its bills are booked on.
✓  Whether to keep its lines, or book one line.
On your server

Free, private, nothing to subscribe to

✓  PDFs from an invoicing software are read from their own text.
✓  Scans and photos are read by Tesseract, in the languages you set.
✓  Electronic invoices (Factur-X, UBL) are still imported by Odoo from their XML.
✓  Read on upload, only on demand with the Read the Bill button, or off, per company.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_account_bill_ocr and install it.
Needs the pypdf Python package (pip install pypdf). Text PDFs read with nothing more; for scans and photos install tesseract-ocr and poppler-utils on the server, with a Tesseract language pack per language of your bills.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

The whole suite, in one install

Questions we get

What do I need to install on the server?
The pypdf Python package. For scans and photos, Tesseract and Poppler: sudo apt install tesseract-ocr poppler-utils, plus a language pack per language of your bills (tesseract-ocr-fra, tesseract-ocr-deu...).
Can I try it before using it on real bills?
Yes. Sample bills are in the tests/samples folder of the module: US, German, French, Indian and UAE layouts, a scanned PDF and a photo.
Do I need the full accounting app?
No. Vendor Bill OCR works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
