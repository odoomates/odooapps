How it works

Design, select, export

The file the bank or the office asks for, without a spreadsheet in between.

1

Design the layout

The model, the format and the file name, then the columns of the lines, and of the header and footer if the file needs them.
2

Select the records

In their list view, open the Action menu and choose Export: followed by the name of the layout.
3

Check and download

The preview shows the file and its problems. Download it; it is kept to download again.
The layout

Column by column

Each column is a Python expression of the record, e.g. record.name, with its type and how it is written: width, alignment, padding, upper case, decimals and decimal separator, implied decimals (1500.00 as 150000), date format. The expressions also read today, now, count, total, company and user. A header written once, one line per record, and a footer written once, e.g. the number of lines and their total.

Exporting

In the Action menu of the records

Each layout appears in the Action menu of its model as Export: followed by its name. The export shows a preview of the file and its problems, e.g. an empty required value or a value longer than its column, before you download it.

Every export

Every file kept

Every file exported is kept, with who exported it, when and for which records, to download it again as it was sent and to open its records. Each user reads the files they exported; the administrators read them all.

Features

Everything a file needs

From the first column to the file the bank accepts.

📄

CSV, fixed width or Excel

The separator and quotes of your choice; the CSV and Excel files can start with a row of the column titles.
📑

Header, lines, footer

A header written once, one line per record, a footer with e.g. the number of lines and their total.
📐

Every column formatted

Width, alignment, padding, upper case, decimals, implied decimals and date format.
🔤

Encoding and line ending

UTF-8, UTF-8 with BOM, Windows-1252 or ASCII; Windows or Unix line endings.
🏷️

The file name

e.g. SALARY_{date}, with {layout}, {date}, {datetime} and {company} replaced.
⚠️

Problems before you send

An empty required value, a value longer than its column: named in the preview.
🗃️

Every export kept

Who exported it, when, for which records; download it again as it was sent.
🏢

Multi-company

A layout belongs to one company or is shared by all of them.

How to use it

1.  Give File Layouts: Administrator to the people who design the layouts (Settings, Users & Companies, Users); the other users can read the layouts and export with them.
2.  With the developer mode, Settings, Technical, File Layouts, File Layouts: the model, the format and the file name, then the columns of the Lines tab, and of the Header and Footer tabs if the file needs them.
3.  Select the records in their list view, open the Action menu and choose Export: followed by the name of the layout.
4.  Check the preview and the problems, then click Download. Find every file in Settings, Technical, File Layouts, Exports, or from the Exports button of the layout.
