# Getting help

| You want to… | Go to |
|---|---|
| Ask how to install, configure or use a module | [Discussions](https://github.com/odoomates/odooapps/discussions) |
| Report a bug | [Issues → Bug report](https://github.com/odoomates/odooapps/issues/new/choose) |
| Suggest a new feature or an improvement | [Issues → Feature request](https://github.com/odoomates/odooapps/issues/new/choose) |
| Report a security vulnerability | Email, never a public issue: see [SECURITY.md](SECURITY.md) |
| Get support, customisation or a new module | [odoomates@gmail.com](mailto:odoomates@gmail.com) |

## Before you ask

- Read the description page of the module (on the Odoo Apps Store or in
  `static/description/index.html`). The accounting modules also come with a user
  guide: `om_account_accountant/static/description/user_guide.pdf`.
- Search the [issues](https://github.com/odoomates/odooapps/issues?q=is%3Aissue)
  and [discussions](https://github.com/odoomates/odooapps/discussions), open and
  closed: your question may already have an answer.
- Update to the latest commit of your branch: the problem may already be fixed.

## Supported versions

Bugs are fixed on **18.0, 19.0 and 20.0**. Older branches stay available but
receive no more fixes.

The help on GitHub is given for free, when the maintainers have time. There is
no guaranteed answer time.
