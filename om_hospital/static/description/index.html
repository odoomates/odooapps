Fields and the ORM

Learn every common field type, from dates and relations to computed, monetary and image fields, and the business logic around them: create, write, unlink, constraints, copy and display names. Then use the ORM from Python and the shell, and build wizards with transient models.

Reports, Mail and Integrations

Learn how Odoo talks to the outside world: PDF reports with QWeb, the chatter and email templates, webhooks and controllers, and the external API. Each topic is applied to om_hospital, so you print patient cards, post messages, send emails and read or create patients from a script.

Reports · Mail · Integrations · External API

Look under the hood of Odoo: query its PostgreSQL database, read and fix common errors, and run Odoo on a real server with Nginx, HTTPS, workers and backups, or on Odoo.sh. You also set up the tools that make daily work faster, and learn how to publish a module on the Apps Store.

A migration guide for module developers, one section per version of Odoo: the code changes you must make when you move a module from the version before, with the old and the new code side by side, plus short videos on what is new in the interface.

Every lesson, up to date for Odoo 19

Each lesson is a video of Odoo Mates. When the video was recorded on an older Odoo, the lesson says what is different in Odoo 19, with the new code: attrs, tree views, the chatter, constraints, security... The course What Changed in Odoo is the checklist to migrate your own modules.

Each section starts with an article that points to the code of om_hospital, and ends with a quiz: points and ranks of eLearning included.

om_hospital: the app the lessons build

✓  Patients, doctors and appointments, with sequences, a chatter and tracking
✓  A status bar with buttons, computed and related fields, constraints, onchange
✓  List, form, kanban, calendar, activity and search views, with a search panel
✓  Wizards, a server action, notifications, a settings page
✓  A PDF patient card with a QR code, and a field added to the sales orders

How to use it

1.  Download the module and add it to the addons path of your Odoo 19.
2.  Install Odoo 19 Development Tutorials from Apps: it installs eLearning too.
3.  Open eLearning (or Courses on your website): the six courses are there, published, ready to follow.
4.  Watch a lesson, read what changed in Odoo 19, open the code of om_hospital, try it in the Hospital app, then take the quiz.

Everything stays in your database. The videos play from YouTube, so watching them needs an internet connection.
