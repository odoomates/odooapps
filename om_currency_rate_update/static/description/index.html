Features

A closer look

Sources

The rates of the source you trust

✓  Frankfurter and the European Central Bank, no key needed.
✓  Open Exchange Rates with an App ID, ExchangeRate-API with or without a key.
✓  A backup source for the currencies the main one does not quote.
✓  Converted to the currency of the company, whatever the source quotes in.
✓  Every active currency, or only the ones you name.
Safeguards

A wrong rate never slips into the books

✓  Set a maximum change: a rate moving more than that is held back and listed in the result.
✓  Rates dated as the source dates them, or on the day of the update.
✓  A rate of the day already there is updated, not doubled.
✓  A failing company never stops the others; its next date is set all the same.
✓  The keys are readable only by administrators and never shown in an error.
How it works

In three steps

1
Pick the source
In the accounting settings, with a backup source if you like.
2
Set the schedule
Daily, weekly or monthly, and the currencies to update.
3
Check the result
Test Connection first; the last update and its result stay on screen.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_currency_rate_update and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

Which source should I pick?
Frankfurter or the European Central Bank cover about 30 major currencies without a key. For every currency, use Open Exchange Rates or ExchangeRate-API, as the source or as the backup source.
What happens to a rate that is held back?
It is not saved. The result of the update lists the currencies held back, for you to check and enter by hand. Leave the maximum change at 0 to save every rate.
Do I need the full accounting app?
No. Automatic Currency Rates works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
