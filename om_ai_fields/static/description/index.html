Your AI, your key
Built on the free AI Engine (om_ai): the requests go from your Odoo server straight to the provider you choose, with your key, or to a model server on your own machine. Nothing goes through Odoo Mates. Every call is in the AI usage log, within your daily limits.
AI fields

A prompt per field

Pick a field, or create one, and write what the AI is asked.

Field types
One-line and long text, formatted text, selection, link to a record (by name), checkbox and numbers.
New fields
Create a field from the AI field: it is added to the model and shown on its form, in an AI tab.
Record values
Use {{ name }}, {{ partner_id.name }} or {{ order_line.product_id }}. Nothing is evaluated, only readable fields are sent.
Valid values only
The AI answers with JSON: selections take their values, links the names of the allowed records, numbers numbers.

Write the prompt

The prompt lists the record values it uses. Add instructions (tone, length, language), choose the fast or the chat model, or a model of your own, and limit the records a link may take. Try it on one record before you turn it on.

When the AI fills it

Always in the Actions menu. In the background when a record is created or chosen fields change: saving never waits for the AI. On a schedule for the empty values, a set number per run, within a number of records per day.

Fill with AI

Select records in a list, or open one, and use Fill ... with AI. Up to 10 records are filled at once, more in the background.

On the form

New AI fields appear on the form of the model. Values already set are kept unless you choose to replace them.
Automation

Update Fields with AI

A new server action type for automation rules.

Several fields in one call

Choose the fields to fill, write the prompt, and use the action in an automation rule (on create, on change, on a date...) or as a contextual action. In automation rules the records are filled in the background.

The queue

Pending, done and failed records with the error; retry the failed ones. Records are filled as the user who triggered them, so access rights apply.
Good to know
  • You need the AI Engine (om_ai) with a provider and default models set up.
  • Usage is logged under the feature "fields", within the daily limits of the AI settings.
  • Dates, many2many and one2many fields are not filled. Links list at most 200 allowed records.
  • Check the results with your own provider and model before you rely on them.
