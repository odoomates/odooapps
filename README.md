Free and open-source Odoo apps for the Community and Enterprise editions, from
the Odoo Mates team.

Each Odoo version has its own branch (`20.0`, `19.0`, `18.0`…), and the apps
available differ from one version to another.

Some apps add to Community what Enterprise already has, such as Accounting,
Assets, Budgets or Follow-ups. Check an app's description before installing it
on Enterprise.

## Apps on 20.0

### Accounting

| Module | What it does |
|---|---|
| `om_account_accountant` | The full accounting app, installing the modules below together |
| `accounting_pdf_reports` | Financial reports in PDF: balance sheet, profit and loss, cash flow, ledgers, trial balance, aged balances, tax report |
| `om_account_daily_reports` | Day Book, Cash Book and Bank Book |
| `om_account_asset` | Assets and their depreciation board |
| `om_account_budget`, `om_account_budget_purchase` | Budgets against actuals, and budget control of purchase orders |
| `om_account_reconcile` | Bank reconciliation, matching of journal items, reconciliation models |
| `om_account_bank_statement_import` | Bank statements from CAMT, MT940, OFX, QIF, CSV and Excel files |
| `om_account_bill_ocr` | Vendor bills read from PDFs, scans and photos, on your own server |
| `om_account_followup` | Customer payment follow-ups and reminders |
| `om_account_cash_forecast` | Cash balance forecast by week or month |
| `om_account_check_printing` | Cheque formats for the cheques of any bank |
| `om_currency_rate_update`, `om_currency_revaluation` | Exchange rates updated automatically, and balances revalued at the closing rate |
| `om_fiscal_year` | Fiscal years, year-end closing and lock dates |
| `om_recurring_payments` | Payments repeated periodically |
| `om_spreadsheet_account*` | Accounting, assets, budgets and follow-up dashboards in the Dashboards app |
| `om_aed_currency_symbol` | The new UAE Dirham sign for AED |

### Productivity

| Module | What it does |
|---|---|
| `om_approval` | Approval flows for any app: a button waits for its approval before it runs |
| `om_automation_studio` | Workflows designed as a flowchart, without code |
| `om_sign`, `om_sign_print_template` | PDF files sent for electronic signature |
| `om_print_template`, `om_print_template_document` | Certificates and letters printed from any record, with a verification QR code |
| `om_document` | Expiring documents on any record, with reminders and renewals |
| `om_file_layout` | CSV, fixed width or Excel files designed and exported from the Action menu |

### WhatsApp

| Module | What it does |
|---|---|
| `om_whatsapp_base` | Templates, sending and the message log |
| `om_whatsapp` | Through the Meta WhatsApp Cloud API |
| `om_whatsapp_web`, `om_whatsapp_device` | Through WhatsApp Web, or a device linked by QR code |

### Tools

| Module | What it does |
|---|---|
| `om_access_manager` | Access profiles: hide menus, fields and buttons, read-only users, login hours, IP restriction |
| `om_restrict_menu` | Menus hidden by user and company |
| `om_user_audit` | User activity log, login history and active sessions |
| `om_data_remove` | Test data removed from a database |

### Learning

| Module | What it does |
|---|---|
| `om_academy` | Odoo development step by step, for beginners |
| `om_hospital` | The hospital app of the Odoo Mates development tutorials |

## Ideas welcome

Looking for a new feature, or an app that is missing? Let us know: we would
like to discuss it with you and make it possible.

Share your idea in
[Discussions → Ideas](https://github.com/odoomates/odooapps/discussions/categories/ideas)
or open a [feature request](https://github.com/odoomates/odooapps/issues/new/choose).
