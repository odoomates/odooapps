# Odoo Apps

Free and open source Odoo apps by Odoo Mates: accounting
(financial reports, assets, budgets, follow-ups, reconciliation, fiscal years,
dashboards…), payroll and more.

Each Odoo version has its own branch (`20.0`, `19.0`, `18.0`…). The modules are
published under the LGPL-3.0 license.

## Ideas welcome

Looking for a new feature that would improve the accounting bundle? Let us
know: we would like to discuss it with you and make it possible.

Share your idea in
[Discussions → Ideas](https://github.com/odoomates/odooapps/discussions/categories/ideas)
or open a [feature request](https://github.com/odoomates/odooapps/issues/new/choose).
