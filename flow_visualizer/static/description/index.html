Flow Visualizer for Odoo 20

See what a click does behind the screen: the records a button creates, edits and deletes, as a tree of the methods that made them.

Turn it on, then click as usual

A switch in the top bar turns it on for your session. Every click that changes data then appears in a side panel.

Story

The documents a click touched, a quotation, a delivery or an invoice, each with its status and lines, linked to the document that caused it.

Technical

The tree of methods behind the click, with the records each one created, edited or deleted, field by field.

Jump to the code

Open a traced method in the editor of the machine when Odoo runs on it, or on the web page of its git repository.

The flow of any saved record

Show Flow in the gear menu of a form opens the documents linked to that record.

Linked documents

From a quotation to its deliveries, invoices and payments, found through their relational fields.

Timeline

When each document was created, its key dates and the status changes its chatter logged.

Go back

Reset the later documents and return to an earlier point. You see the plan first, and it applies to all of them or none.

Try a process without keeping it

The simulator runs your clicks in one open transaction, on a local server.

Nothing is saved

While it runs, every click stays in a single transaction, emails are not sent, and stopping the server leaves no trace.

Step back

Each click that changes data becomes a step you can return to.

Keep or discard

Keep the simulation to commit everything, or discard it to return to where you started.

Good to know

What to expect before you install.

  • It is a tool for administrators: only users with the Administration: Settings access can use it, and nothing is traced until one of them turns it on.
  • Passwords, keys, tokens and system parameters are shown as (hidden) in a trace.
  • The simulator needs a local server with --workers=0, for one person at a time. Do not use it on a production server.
