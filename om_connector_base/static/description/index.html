Everything at a glance

What it gives every connector built on it.

A Job Queue
Every import, export and webhook is a job; two workers never on one job.
Retries
After 2, 4, 8 minutes and more; nothing left half done.
No Duplicates
Jobs with the same key run once, with the newest data.
Mappings
An external ID linked to an Odoo record, once per connection.
Order Workflows
Confirm, invoice, register one or several payments.
Secrets Encrypted
Tokens and keys stored encrypted in the database.
Webhook Signatures
HMAC-SHA256 checked in constant time.
Patient HTTP Calls
Wait and try again on rate limits and server errors.
Customers and Addresses
Contacts found by email, invoice and delivery addresses.
Taxes and Currencies
Taxes found or made from the rates of the shop; a price list per currency.
Refunds

Shipped Orders

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_connector_base and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Free, for good

Connector Base is free and open source under LGPL-3, for Odoo 20. Build your own connector on it, as the Shopify and WooCommerce Connectors do.

Questions we get

How does a connector queue work?
Its connection inherits om.connector.backend.mixin and calls self._connector_enqueue(method, payload, dedupe_key=...). The method gets the job, reads job.payload and returns the record it made.
How are external records linked?
A mapping model inherits om.connector.binding.mixin and uses _connector_find() and _connector_bind().
How do I retry or fail a job?
Raise RetryableJobError(message, delay=60) to try again later, a UserError to fail at once. Orders are processed with workflow._connector_process(order, paid=True).
Do I need Odoo Enterprise?
No. It runs on the Community Edition, and installs on Enterprise as well.
