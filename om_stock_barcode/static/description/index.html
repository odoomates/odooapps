How it works

In three steps

1
Open the Barcode app
On a phone, a tablet or a computer with a scanner. Inventory users can use it.
2
Scan
An operation, a transfer, then locations, products, lots and packages. Or count a location.
3
Validate
Inventory does the rest: stock moves, backorders, adjustments, as from the forms.
Settings

As strict as you need

Per operation type
Scan the source location first, scan the destination, put the products in a package, allow products that are not planned.
Per company
Sounds and vibration on or off, the camera button on or off.
Rights of Inventory
Every scan runs with the rights of the user: an Inventory user is enough, nothing is done as administrator.
Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_stock_barcode and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.
