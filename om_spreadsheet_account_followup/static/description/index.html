Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_spreadsheet_account_followup and install it.
Needs om_spreadsheet_account, om_account_followup and om_account_cash_forecast; installs automatically when they are there.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

The whole suite, in one install

Questions we get

What do I need to install?
om_spreadsheet_account (Accounting Dashboards), om_account_followup (Follow-ups) and om_account_cash_forecast (Cash Forecast). This module then installs by itself; Odoo 18 Accounting brings them all.
Do I need the full accounting app?
No. Follow-ups and Cash Forecast Dashboard works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
