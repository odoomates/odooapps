==================
Adaptive Views
==================

Screens that adapt to how your company works.

Adaptive Views counts how each screen is used - the fields changed when a form is saved,
the filters applied when an action is opened, the optional columns switched on or off,
the menus opened - and turns the counts into changes: fold the fields and tabs nobody
edits, bring forward the fields everybody fills, make the usual filter the default, hide
the filters nobody uses, show or hide columns, put the apps and menus in the order they
are opened.

Roles are learnt apart, each person gets their own default filter and menu order, the
clearest changes can apply on their own with a weekly digest, every change is kept in a
journal, a change can be previewed before it is applied, and the applied changes move
between databases in one file.

Each change is applied with one click and undone with another. Nothing in the views is
rewritten: the changes are applied while Odoo builds the screen, per company. Only names
are counted, never the values typed.

Usage
=====

Settings > Adaptive Views:

* Screen changes: the suggestions with their evidence; Apply, Undo, Dismiss; Analyse now.
* Fields nobody uses: every field of every form saved, with how often it was changed.
* Menus nobody opens: every menu with how often it was opened.
* Screen usage: the raw counts.
* Change journal: every change applied, undone, dismissed or imported.
* Move changes: export the applied changes to a file, import them on another database.

The thresholds, the roles, changes applied on their own, personal defaults, the menu
order and the menus kept in place, the models and fields left alone, and a reset are in
General Settings, Adaptive Views.
