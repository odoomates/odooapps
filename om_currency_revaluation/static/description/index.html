Features

A closer look

Revalue

See the adjustment before you post it

✓  Open Currency Revaluation from the Closing menu and pick the date.
✓  Receivables and payables revalued on what is open, partner by partner.
✓  Accounts held in a foreign currency revalued on their balance.
✓  Every foreign currency, or only the ones you name, with the total shown first.
✓  Post Adjustment writes one entry, reversed on the date you choose.
Settings

Set it up once, per company

✓  The journal of the adjustment entries.
✓  The unrealized gain account and the unrealized loss account.
✓  Whether the entry is reversed at the start of the next period.
✓  Only accounting managers can post a revaluation.
How it works

In three steps

1
Set the accounts
Journal, unrealized gain and loss accounts in the accounting settings.
2
Pick the date
Usually the last day of the period; the lines compute as you type.
3
Post the adjustment
One entry, with its reversal on the first day of the next period.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_currency_revaluation and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

Do the amounts in the foreign currency change?
No. Only what they are worth in the currency of the company changes; the foreign amounts stay as they are.
Can I revalue the same date twice?
No. The entry already posted for that date is named, and has to be reversed or deleted first.
Where do the closing rates come from?
From the currency rates in Odoo. om_currency_rate_update keeps them up to date for you.
Do I need the full accounting app?
No. Currency Revaluation works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
