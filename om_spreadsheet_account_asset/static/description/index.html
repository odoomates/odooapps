Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_spreadsheet_account_asset and install it.
Needs om_spreadsheet_account and om_account_asset; installs automatically when both are there.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

The whole suite, in one install

Odoo 18 Accounting installs this module with every other one of the suite, the accounting menus and the dashboards, and comes with a user guide for the person keeping the books.

Questions we get

What do I need to install?
om_spreadsheet_account (Accounting Dashboards) and om_account_asset (Assets). This module then installs by itself; Odoo 18 Accounting brings all three.
Do I need the full accounting app?
No. Assets Dashboard works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
