====================
Documents - Project
====================

Bridge between Documents and Project.

* Each project gets its folder in Documents, inside a Projects folder reached by
  the project users. It is renamed with the project.
* The files attached to the project and to its tasks are copied in the folder,
  linked to their task, the customer as their contact.
* Share Documents: share the folder of the project with its customer in one
  click; they find it in their portal.
* Documents smart buttons on the projects and the tasks; a setting per project
  to keep no documents.
