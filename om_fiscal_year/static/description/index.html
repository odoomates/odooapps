Features

A closer look

Year-end closing

Carry the result of the year to retained earnings

✓  Fiscal years of any start month, which cannot overlap.
✓  A closing wizard shows the earnings to transfer, the draft entries and the unreconciled bank lines.
✓  One posted entry from Current Year Earnings to the retained earnings account.
✓  Lock the year in the same step, or reopen it later: the closing entry is reversed.
Period closing

Close a month against a checklist

✓  Automatic checks: draft entries, unreconciled bank transactions, unmatched payments.
✓  Bank and cash accounts in the red, and bills that might be duplicates.
✓  Eleven ready-made closing tasks to mark done, and your own on top.
✓  Closing sets the lock date you chose; reopening puts the previous one back.
Lock dates

The cheapest control in accounting

✓  Sales and purchase lock dates for the invoicing team.
✓  Tax return lock date, so nothing changes a filed return.
✓  Global lock date for everyone, and a hard lock date that cannot be undone.
✓  Reopen a period for 5 minutes up to forever, for you or everyone, with the reason logged.
How it works

In three steps

1
Create the fiscal year
Set its start and end date, or the last day of the year in Settings.
2
Close each month
Work through the checklist and tasks, then close the period.
3
Close the year
Transfer the earnings to retained earnings and lock the year.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_fiscal_year and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

Can I correct something after the year is closed?
Yes. An accounting manager reopens the year: the closing entry is reversed. Lower the lock date first if it covers the date of the correction.
Can I add my own closing tasks?
Yes, under Configuration, Closing Tasks, with a note and a responsible. Every new period closing gets them.
Do I need the full accounting app?
No. Fiscal Year & Lock Date works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
