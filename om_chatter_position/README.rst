Odoo Chatter Position
=====================

* Each user chooses where the chatter sits on a form, in My Preferences
* Automatic: Odoo's own choice, beside the form on wide screens and below it on
  narrower ones
* Below the form: always underneath, the form taking the whole width
* Beside the form: next to the form on laptop and desktop screens; phones and
  small tablets keep Odoo's layout

Depends
=======
[web] and [mail] addons Odoo

Tech
====
* [Python] - Models
* [XML] - Odoo views
* [JavaScript] - Form layout
* [SCSS] - Stylesheet
