Documents - Accounting

Turn documents into vendor bills, customer invoices and credit notes, and keep the files of the invoices in an Accounting folder.

Bills from documentsInvoices and credit notesWorkflow actionsAccounting folderFree, LGPL-3
Needs Documents and Invoicing. Reads the bills when a module reading PDFs is installed, e.g. Vendor Bill OCR.
Overview

From a file to a bill

Create Bill
A vendor bill from a document, its file as the main attachment.
Invoices and Credit Notes
Customer invoices, vendor and customer credit notes too.
Read Like an Upload
E-invoices and, with a reading module, PDFs and scans fill the bill.
Workflow Actions
A folder action creates the bills, tags and moves the documents.
Accounting Folder
The files of the invoices and bills, tagged, with the partner.
Linked
The document opens its invoice; the invoice shows its documents.

Questions

Good to know

Does it need Vendor Bill OCR?
No. Without a module reading PDFs, the bill is created with the file attached and you fill it; with one, it is read for you.
Is the same invoice file added twice?
No. A file already kept for an invoice is not added again.
