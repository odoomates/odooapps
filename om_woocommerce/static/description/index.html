Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_woocommerce and install it.
It installs Connector Base (om_connector_base), Sales and Inventory with it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

What do I need on the WooCommerce side?
WooCommerce 3.5 or newer on an https site, and an administrator who approves Odoo, or a REST API key with the Read/Write permission (WooCommerce → Settings → Advanced → REST API). No plugin to install.
Do I need webhooks?
No, but they make orders arrive in seconds. WooCommerce sends them to an https address only: set the public address of your Odoo on the store and click Sync Webhooks. Without them, orders come every 15 minutes.
How are the images of exported products sent?
Through the media library of WordPress, with a WordPress user and one of its Application Passwords (Users → Profile). Without one, the products are exported without images.
Can I connect several stores?
Yes, as many as you want, in one or several companies, each with its own warehouse, workflows, price lists and settings.
What if an order is missed?
Orders are also fetched every 15 minutes from the last import, and any order can be imported by its number. A webhook sent twice runs once.
How are refunds handled?
A refund in WooCommerce becomes a credit note, paid in the journal of the payment method, with a return if you want. A credit note refunded from Odoo is refunded in WooCommerce, through the payment gateway if you want, with or without restock.
Who can use it?
Two levels of rights: WooCommerce users see the stores, orders, coupons and jobs; managers set up the stores and see the keys, which are stored encrypted.
Do I need Odoo Enterprise?
No. It runs on the Community Edition, and installs on Enterprise as well.
