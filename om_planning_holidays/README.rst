===================
Planning - Time Off
===================

Bridge between Planning and Time Off, installed automatically with both.

Features
========

* Approved time off greys the employee's row on the Gantt and is a conflict
  on the slots it overlaps, with the type of time off.
* Time off still to approve is a conflict too, so the planner sees it before
  it is approved.
* A company policy decides what happens to the planned slots when a time off
  is approved: keep them, keep them and notify the planners, or unassign the
  employee (the slots become open shifts) and notify the planners.

Configuration
=============

Planning > Configuration > Settings > Time Off.
