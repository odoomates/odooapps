Odoo Mates Theme Lite
=====================

* The familiar plum and teal look of Odoo on the Community backend: plum
  buttons, teal links, white cards on a soft canvas, underlined fields, soft
  dropdowns, tinted status badges and boxed notebook tabs
* A home page listing every app as a tile; search that reaches menu items inside
  apps, best match first, typos forgiven
* Arrow keys, Enter and Escape on the home page; drag tiles into your own order;
  tiles are links, so middle-click opens an app in a new tab
* Dark mode for Community: Light, Dark or System (follows the device), per user
* A login page that matches the backend and follows the device, light or dark
* A home screen background and a favicon per company, in Settings > Theme
* An optional apps sidebar, per user (icons, or icons and names)
* A clearer chatter: messages, notes and field changes each with their own look;
  beside the form or below it, resizable, field changes can be hidden
* A full screen button on large dialogs, or full screen by default
* A refresh button next to the pager, list column widths that are remembered,
  list totals that stay in view, bigger tap targets on phones
* The launcher becomes the home page on install; uninstall gives it back
