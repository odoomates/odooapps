Features

A closer look

Categories

Set a category up once, and every asset inherits it

✓  Asset account, depreciation account and expense account.
✓  Linear or degressive, with the number of depreciations and their period.
✓  Prorata temporis to start on the purchase date, not the first of the period.
✓  Assets created automatically from a vendor bill line carrying the category.
✓  Vendor refunds create negative assets, linked to the asset they refund.
✓  One asset from several bill lines or journal items, with Create Asset.
✓  Taxes booked on the asset account added to its value.
✓  Prorata by constant periods or by the days of each period; salvage value in %.
Assets

A board you can read, and correct

✓  Confirm to put the asset in service; entries are posted period by period.
✓  Modify the number or length of depreciations and the remaining lines are recomputed.
✓  Sell it against the customer invoice, with the gain or loss booked.
✓  Or dispose of it, with the reason logged on the asset.
✓  No Depreciation for land or assets under construction, then Activate Depreciation.
✓  Asset groups, custom properties per category, and standard categories in one click.

How it works

In three steps

1
Create a category
Pick the accounts, the journal and the depreciation method once.
2
Register the asset
Enter it by hand, or post a vendor bill with the category on its line.
3
Let it run
Entries post on their date; follow the figures in Assets Analysis.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_account_asset and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

The whole suite, in one install

Questions we get

How is the gain or loss on a sale computed?
From the customer invoices you pick in the Sell wizard, against the book value on the sale date, and booked on the gain or loss account of the category.
Where is the dashboard for assets?
Install om_spreadsheet_account_asset for an Assets dashboard in the Dashboards app; Odoo 18 Accounting installs it for you.
Do I need the full accounting app?
No. Asset Management works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. Everything on this page runs on the Community Edition.
