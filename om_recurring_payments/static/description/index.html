Features

A closer look

Templates

Say once how it repeats

✓  The bank or cash journal the payments go through.
✓  Every so many days, weeks, months or years.
✓  Generate the payments in draft to check them, or posted.
✓  As many templates as you have repeating commitments.
Recurring payments

Then let the payments come on time

✓  A partner, an amount, a start and end date, and a template.
✓  Every payment date is listed on the record before it is due.
✓  Created by a daily scheduled action, or at once with Create Payment.
✓  Skip a date, reset it, or stop the schedule early.
✓  A payment that fails shows why and warns the responsible.
How it works

In three steps

1
Create a template
Pick the journal, the frequency and whether payments are posted.
2
Set up the payment
Partner, amount, start and end date, then confirm it.
3
Let it run
Payments are created on their date; check them under Recurring Payments.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_recurring_payments and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

Does it create journal entries or payments?
Payments, in the journal of the template, in draft or posted. For entries, invoices and bills that repeat, set Auto-post on them in Odoo and follow them under Auto-Post Entries.
What if a payment cannot be created?
The error is kept on its line, posted in the chatter and assigned to the responsible as an activity. The other payments go on.
Do I need the full accounting app?
No. Recurring Payments works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. It runs on the Community Edition, and installs on Enterprise as well.
