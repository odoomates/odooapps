========================
Rental - Stock Planning
========================

Bridge between Rental - Planning and Rental - Stock, installed automatically
with both.

Features
========

* "Serial Numbers as Units" on rental products tracked by serial number: each
  serial number becomes a rental unit (a planning resource linked both ways),
  also the serial numbers received later.
* The serial booked on the order line is set aside for the rental and
  proposed at the pickup, so the stock moves of the pickup and of the return
  use the booked serial number.
* A different serial picked up takes the place of the booked one in the
  planning.
* Picked up and returned serials move the bookings of their units like any
  rental by units.
