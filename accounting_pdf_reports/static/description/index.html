Custom reports

Your own financial reports, in their own menu

Not only the Balance Sheet and the Profit and Loss: set up a report of your own, a management P&L, operating expenses, a gross margin, and open it from a menu of its own, like the standard ones.

Add to Menu, on the form of the report.
Its menu opens the report, ready to print.
1
Build the report
In Configuration > Accounting > Financial Reports, create a report and add its sections: accounts, account types, the value of another report, or the sum of the sections below.
2
Add to Menu
On the form of the report, click Add to Menu, then pick the menu name, the parent menu and the position among its menus.
3
Print it
Open the new menu: the report wizard opens with the report chosen. Set the dates, a comparison if you need one, and print the PDF.
✓  Each section has its sign and its level of detail: no detail, its accounts, or its accounts by hierarchy.
✓  Remove Menu takes the menu away again; deleting the report removes its menu too.
✓  Accounting managers add the menus; the menu shows for the users who see the statement reports.
✓  With Dynamic Accounting Reports installed, the same menu opens the report on screen.

Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search accounting_pdf_reports and install it.
Needs only Invoicing (account).
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

Does it work with my chart of accounts?
Yes. The statements are built from the account types, so any localization works.
Can I read the reports on screen or in Excel?
Yes. The free om_dynamic_reports shows them on screen with drill-down, and exports them to PDF, Excel and CSV. Our paid add-on accounting_excel_reports adds Print Excel to the report wizards of this module.
Can I print a single journal entry?
Yes, with the free om_print_journal_entry module (installed with om_account_accountant, or on its own): Print > Journal Entries on any entry, invoice or bill.
Do I need the full accounting app?
No. Financial Reports works on its own. For complete accounting, install om_account_accountant, which brings it together with the rest of the suite.
Do I need Odoo Enterprise?
No. It runs on the Community Edition, and installs on Enterprise as well.
