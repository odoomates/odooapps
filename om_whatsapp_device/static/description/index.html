Link your WhatsApp to Odoo with a QR code, as you link WhatsApp Web. Invoices, order confirmations and replies then go and come from the server, with no browser open and no Meta account. Scan, and send.

Set up

A QR code, and you are linked

Odoo becomes a linked device of your WhatsApp, kept connected on your server by the WhatsApp Bridge of the module.

1

Install, and run the bridge

Install the module, and on your server Node.js and the packages of its WhatsApp Bridge, once. Then click Start the Bridge, or run it as a service.

2

Scan the QR code

Link WhatsApp shows the QR code, live. On your phone: WhatsApp › Linked devices › Link a device, and scan it.

3

Send and receive

From the composer, the chatter, Discuss and automation rules: from the server, with no browser open.

✓  Or link with a code typed on the phone, without scanning.

✓  Your own number: your customers see the chat they already have with you, and your phone keeps working.

✓  Odoo checks the bridge every 5 minutes, starts it again, and tells you when the phone unlinks it.

Installation

Install it, step by step

On the server of Odoo, once. Ubuntu shown; any Linux with Node.js 20 or later does.

1. Node.js 20 or later

The nodejs of Ubuntu 24.04 is 18, too old: take it from NodeSource.

sudo apt remove -y nodejs npm
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node --version

Odoo runs the node of its PATH; another one (nvm...) goes in the system parameter om_whatsapp_device.node, with its full path.

2. The packages of the WhatsApp Bridge

Once, and again after each update of the module:

cd /path/to/om_whatsapp_device/bridge
npm ci
npm test

3. The module

Put the module in the addons_path of Odoo, restart Odoo, then Apps › Update Apps List, and install WhatsApp Connector QR: it brings WhatsApp Connector Base.

4. Link your WhatsApp

  1. WhatsApp › Configuration › Accounts › New: a name, the provider WhatsApp QR (Linked Device), the users who answer. Save. The form shows these steps until the account is linked.
  2. Click Start the Bridge (administrators). Or run the bridge as a service of the server, systemd or Docker, with the secret of the tab WhatsApp QR: see bridge/README.md in the module.
  3. Click Link WhatsApp: the QR code shows, live.
  4. On your phone: WhatsApp › Settings › Linked devices › Link a device, and scan the code. No camera at hand: Link with a phone number instead, and type the code on the phone.
  5. The account turns Linked: send from a contact, a document or Discuss.

✓  Odoo is not on http://127.0.0.1:<its port>? Set its address in the system parameter om_whatsapp_device.odoo_url.

✓  Run Odoo with its scheduled actions (not --max-cron-threads=0): they check the bridge and bring the profile pictures.

✓  Several databases on the server? One bridge serves them all: no dbfilter needed.

From the server

Sent without a browser

Unlike WhatsApp Web, nothing has to stay open: messages go from the server, also from automation rules and scheduled actions.

✓  An automation rule sends the invoice or the order confirmation, with its PDF, when it is posted or confirmed.

✓  As a person sends: one message at a time, typing first, a random pause between two.

✓  A number of messages a day you set; the rest waits for tomorrow, in a queue.

✓  Each message on the chatter of its document, with its ticks; a failure in red, with the reason, ready to send again.

Two-way chat

The replies come back to Odoo

Each customer gets a WhatsApp conversation in Discuss, shared by the users of the account; a reply also goes to the chatter of the document it answers.

✓  A WhatsApp tab in the messaging menu; the chat window opens when a customer writes.

✓  Pictures, documents, stickers and voice messages with their files; reactions on the messages.

✓  Sent, delivered and read ticks.

✓  Messages typed on your phone come to Odoo too.

✓  Groups, status and channels stay out of Odoo.

Questions we get

What does my server need?
Node.js 20 or later next to Odoo, for the WhatsApp Bridge of the module: on premise or a VPS. Odoo Online does not let a program run next to Odoo: there, use WhatsApp Connector Web, which needs nothing on the server.

Is it the official API of WhatsApp?
No. Your Odoo is a linked device of your WhatsApp, as WhatsApp Web is. WhatsApp may ban a number that sends too much, too fast, or to people who did not ask for it: the module sends one message at a time, with the pause of a person and a number a day you set. For campaigns, use the official Cloud API of Meta (WhatsApp Connector Meta, coming soon).

Does my phone keep working?
Yes: it is your WhatsApp, with Odoo as one of its linked devices. Your phone sends and receives as before, and what you type on it comes to Odoo too.

And when WhatsApp changes?
WhatsApp changes its protocol a few times a year: the bridge then needs an update of its library, as any linked device does. Odoo tells you when the bridge stops or the phone unlinks it.

What is the difference with WhatsApp Connector Web and Meta?
WhatsApp Connector Web sends from the WhatsApp Web of your browser, one message a click, with nothing on the server. This module sends from the server, for automation too, with a QR code. WhatsApp Connector Meta, coming soon, uses the official API of Meta. All share the same base, conversations and templates.
