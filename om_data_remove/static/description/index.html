How it works

From setup to go-live

1
Configure and test in live
Install this module in the database you will go live with, set Odoo up and test every flow there.
2
Clear the transactions
Settings > Data Cleaning → Clear All Transactions, type DELETE. Then Delete Rows on the tables of your custom models, if any.
3
Uninstall it, go live
Uninstall Remove Data from Apps before the first real transaction, so nobody can clear the live data later.
Install

Get started

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search om_data_remove and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves this module half loaded.

Questions we get

What happens to my custom modules?
Clear All Transactions covers every standard Odoo app. The documents of custom, third-party and Enterprise-only apps stay, and the table report shows them: Delete Rows on their tables empties them too.
Why uninstall it before going live?
Once real transactions exist, clearing them cannot be undone. Without the module there is no button left to press by mistake.
Can I clear one company only?
No. The transactions of every company of the database are cleared. Use it before any company goes live, not when one is live and another is still being set up.
Can I undo a clearing?
No. If you want a way back, keep a copy of the database from before the clearing.
Do I need Odoo Enterprise?
No. It works on the Community Edition and on Enterprise.
