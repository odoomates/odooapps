Where

One more entry in the Print menu

Open a journal entry, an invoice, a bill or a payment entry, open the ⋮ menu, then Print › Journal Entries. Select several entries in the list to print them in one go.

The PDF

Everything an accountant checks, on one page

On your company letterhead, the entry says what it is (journal entry, customer invoice, vendor bill...) and shows:

✓The details: journal, accounting date, invoice and due date, partner, reference, source document and a status badge (draft, posted, cancelled).
✓The lines: account, partner, label, analytic distribution, taxes, debit and credit, and the amount in currency when the entry is in another currency.
✓The totals of debit and credit.
✓A tax summary: the base and the amount of each tax of the entry.
✓Columns that would be empty are left out: no taxes column on an entry without taxes, no analytic column when analytic accounting is off.

Install

Install Print Journal Entries: it only needs Invoicing or Accounting. Nothing to configure.

Already using Accounting PDF Reports? This print came from it, and that module now installs this one for you: nothing changes for your users.
