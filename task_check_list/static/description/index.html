Task Check List

Configurable checklist for project tasks

Version 19.0 Community Enterprise

Overview

Add a configurable checklist to project tasks. Track completion progress with a visual indicator and manage checklist items per project or globally as a fallback.

HIGHLIGHTS

Project-specific checklists

Define checklist items scoped to a project. Tasks in that project will only see their own items, keeping checklists relevant and focused.

Global checklists as fallback

Items without a project assignment are shown to tasks whose project has no own checklists — a sensible default for projects that don't need customization.

Drag-and-drop ordering

Reorder checklist items with a handle in the admin list view. The order is respected in every task form.

Progress tracking

A pie-chart progress indicator in the task form and a progress bar in the task list give an instant view of completion status.

Spanish translation included

Full ES translation provided out of the box.

HOW TO USE

  1. Go to Project → Configuration → Task Checklist.
  2. Create checklist items. Set a Project to scope them, or leave it empty for a global fallback.
  3. Use the Sequence handle to drag items into the desired order.
  4. Open any project task and go to the Checklist tab.
  5. Check off completed items — the progress indicator updates automatically.
