Questions

Good to know

Can a user see a folder without access?
No. The folders and their documents follow the access rules: a folder a user cannot reach is not shown, nor its files.
Does the old Document Expiry app keep working?
Yes, side by side. Documents - Expiry brings document types, expiry dates, reminders and renewals to the documents.
How do emails become documents?
Give a folder an email alias. Each file of an email sent to it becomes a document, the sender as its contact.
What happens when a link expires?
The page says it has expired and nothing can be downloaded or uploaded; the refusal is logged.
Is the file stored twice when a record keeps it too?
No. Odoo stores each file once in its file store: the copies are records pointing to the same file.
Can other apps keep their files in Documents?
Yes. A model inheriting om.documents.mixin gets a Documents button and its files copied in its folder; the bridges use it.
