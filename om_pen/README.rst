Odoo Mates Pen
==============

A visual, no code Studio for Odoo:

* Edit forms, lists, kanban, search, calendar, pivot, graph and activity views by
  clicking and dragging on the real screen
* Add fields of any kind, tabs, columns, smart buttons, header buttons, ribbons,
  a chatter and stages
* Build new apps with their menus and icon, and edit the menus of any app
* Design PDF reports from blocks, or add blocks to the reports of modules
* Approvals on buttons, automations and access rights
* Drafts, undo and redo, published versions, translations and a health check
* Export everything as an installable module, and import it back

Depends
=======
[web] addon Odoo

Tech
====
* [Python] - Models
* [XML] - Odoo views
* [JavaScript] - OWL components

============
